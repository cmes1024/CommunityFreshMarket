# Community Fresh Market

面向中小商户的**私域经营工具**：微信小程序（顾客端 + 商家端）+ Java 后端。

不做在线支付，聚焦商品介绍、预约履约（配送 / 自提）与后续会员经营；当面收款在线下完成。

## 当前阶段

产品概念与分期已对齐，工程代码尚未启动。

## 技术方向（预定）

| 层 | 选型 |
|----|------|
| 客户端 | 微信小程序；顾客 / 商家分包 |
| 服务端 | Java API（非云函数） |
| 数据 | 关系库；按 `storeId` 隔离 |

## 分期概要

1. **第一波**：商品、预约下单、商家接单履约、地址簿、微信客服、有货/售罄、订阅消息
2. **第二波**：积分、图像选品、简单库存
3. **第三波**：优惠券、到店收银、会员快速定位
