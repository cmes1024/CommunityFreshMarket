# 门店主题

日期：2026-10-14  
状态：已定

## 决定

商家在门店设置的「门店」里选主题。按钮上写颜色名：青绿（默认）、赭石、绛红、海蓝。色相分别偏向生鲜、早点、饭馆、商超，不把行业写在按钮上。没覆盖到的店用「自定义」定一个主色，色相滑杆，不逐项改色。

品牌色（主色、按下、进度、页面底、浅底、描边、正文、深色头图底、无图菜色占位）跟着主题走。价格、待确认、售罄红保持固定，不跟店换色。

选中后设置页立刻预览。点「保存设置」后顾客端和商家端一起换。没保存就离开，下次进来仍是已保存的主题。

## 怎么生成

青绿是手调色板，和改主题之前的界面一致，不走生成公式。

赭石、绛红、海蓝：只取色相，饱和度约 62%，明度压在大约 16%–40%，白字对比度至少 4.6:1。绛红因此深于售罄红。按下、页面底、正文、次要字再按这个主色推出，正文和次要字在白底上至少 4.5:1。

自定义滑杆仍是色相 0–359。饱和度用 84%，明度放到白字对比度仍不少于 4.6:1 的最亮一档，最高约 64%。红、橙、绿、蓝、紫因此能拉开，不再挤在同一档深色里。正黄仍会偏深，否则白字按钮看不清。已保存的自定义色按色相重算到这档。

自定义没有色值时，按青绿显示。

## 数据

`store.theme_preset`：`PRODUCE`（默认）/ `BREAKFAST` / `EATERY` / `MARKET` / `CUSTOM`。  
`store.theme_primary`：仅 `CUSTOM` 时存 `#rrggbb`，其余为空。

店铺摘要和门店设置读写这两个字段。小程序用它们生成 CSS 变量，写到每个页面的 `page-meta`，并记一份本地缓存，避免下次打开先闪成别的颜色。
