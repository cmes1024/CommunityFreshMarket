# 商家商品布局与多图设计

日期：2026-10-07  
依据：产品 `2026-10-07-product-design.md` §2.2 / §2.5 / §2.8；技术 `2026-10-07-technical-design.md`；UI `2026-10-07-ui-prototype.md`；可点稿 `docs/prototypes/index.html`

## 背景

商家商品列表与编辑页纵向过松，一屏可见商品少。同时需要支持最多 3 张商品图，顾客详情半屏/整页轮播。

## 决策

### 商家商品列表

- **两列卡片 · 图作蒙层底**：封面铺满卡片 + 渐变蒙层；名称（最多两行省略）/ 价格·单位 / 规格叠在图上；无单独图区
- 卡底半透明条：上架、有货、首页推荐三开关（保证可点可读）；无状态 chips
- 无封面时用浅色底 + 深色字；点图文区进编辑；顶栏保留「分类管理」「新增商品」；其下名称搜索 + 分类/推荐筛选

### 商家编辑/新增

- 图片：最多 3 张，小方图网格；可增、可删；顺序即轮播顺序，第一张为封面
- 表单收紧（小图区、较低输入高度）；字段：名、单位、规格、价、分类、首页推荐
- 上架/有货以列表快捷切换为主；首页推荐列表与编辑页均可设

### 数据与 API

- `image_urls` JSON 数组 ≤3；`image_url` = 第一张（兼容列表/篮）
- 响应：`imageUrl` + `imageUrls`；旧单图兼容为单元素数组

### 顾客端

- 首页/分类/篮：仍用封面 `imageUrl`
- 详情半屏与整页：`swiper` 轮播 `imageUrls`；仅 1 张不显示指示点

## 明确不做（本变更）

- 超过 3 张、图内标注、CDN 变换规格等

## 验收

1. 商家列表一屏可扫更多 SKU，双开关可用  
2. 编辑页可维护 0～3 张图并保存  
3. 顾客详情多图可滑；单图无点；列表缩略图为第一张  
4. 原型 `m-products` / `m-product-edit` / `c-product` 与上文一致
