# 配色收束

日期：2026-10-08  
状态：已定，并落到小程序与 `docs/prototypes`

## 问题

界面同时存在三套「绿」和若干临时色，看起来不像一个店：

- 导航 / 链接是青绿 `#0F766E`，主按钮却是另一支草绿 `#16A34A`，进度又用荧光青 `#2DD4BF`
- 「顾客已到店」用青色（`#0E7490` / `#CFFAFE`），和品牌无关
- 待确认、警告底有四五档琥珀（`#FEF3C7`、`#FFEDD5`、`#FFFBEB`、`#FFF7ED`、`#FDBA74`）
- 无图占位用高饱和薄荷和亮黄；售罄有的黄、有的灰
- 券的「已领」再用第三支绿 `#166534`
- `styles/variable.wxss` 仍是模板遗留：蓝 `#007BFF`、粉 `#EF95DD`、紫 `#A58EF6`、微信绿 `#07C160`。隐私弹层还在用这套

## 原则

1. **品牌只有一条青绿。** 主按钮与 Tab、链接同色。按下用更深一档，进度用同色相浅一档。
2. **语义色只有三组：价格、待处理、危险。** 每组一个字色，浅底和描边各一档。有货、成功、已领复用品牌浅底，不再另起绿色。
3. **「已到店」用实心品牌色**，靠填充和文案与普通浅底标签区分，不用青色。
4. **无图只有三块占位**：菜（冷青绿）、果（暖沙）、售罄（中性灰绿）。售罄不再用亮黄。
5. 小面积状态点用主色和次色，不再用荧光青。
6. 遗留变量名保留，但数值改指这套色板，避免加载动画和协议弹层突然变粉变蓝。

## 明确不改

布局、文案、状态机、按钮种类都不动。`--color-cta` 这个名字保留，值与 `--color-primary` 相同，避免改一批类名。
