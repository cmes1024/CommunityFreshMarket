# 首页推荐与商家商品筛选设计

日期：2026-10-07  
依据：产品 `2026-10-07-product-design.md` §2.2 / §2.5；技术 `2026-10-07-technical-design.md`；UI `2026-10-07-ui-prototype.md`

## 背景

顾客首页「想买点什么」目前取上架商品前若干条，商家无法指定推荐。商品变多后，商家列表也缺搜索与筛选。

## 决策

### 数据

- `product.home_recommended`：布尔，默认 `false`（存量商品不推荐）
- 顾客任意列表/详情：**未上架一律不展示**；推荐开关只决定是否进入首页推荐区

### 顾客首页

- 推荐区只展示 `on_shelf = true` 且 `home_recommended = true`
- 排序：有货优先，再按更新时间；不做拖拽排序
- 无推荐时不显示类目快捷。空态「暂无推荐，去分类逛逛」，其中「去分类逛逛」可点进分类。右上角为「查看全部」
- 分类页不受该字段影响

### 商家商品列表

- 工具栏下：名称模糊搜索（短防抖）+ 分类筛选（全部 / 本店分类）+ 首页推荐筛选（全部 / 仅推荐 / 未推荐）；三者同时生效
- 第一波：全量拉取后前端过滤
- 卡片底开关顺序：上架 → 有货 → **首页推荐**

### 新增/编辑

- 表单增加「首页推荐」开关（默认关），随保存提交
- 列表快捷开关不依赖进编辑页

### API

- 响应/保存增加 `homeRecommended`
- `PUT /api/v1/merchant/products/{id}/home-recommended`（与上架/有货同级）
- 顾客 `GET /api/v1/products?homeRecommended=true`（首页用）；不传则行为不变

## 明确不做

- 推荐排序拖拽、推荐数量上限、定时推荐

## 验收

1. 默认不推荐；未标推荐不上首页推荐区；未上架不上任何顾客列表  
2. 列表三开关与编辑页均可改推荐  
3. 商家列表名/分类/推荐筛选可用  
4. 原型 `m-products` / `m-product-edit` 与上文一致
