## 1. 设计目标

- 社区生鲜**预约履约**，非支付电商、非大促风
- 顾客：逛 → 加购 → 配送/自提 → 看单
- 商家：马上处理订单 → 商品/分类 → 时段设置
- 微信小程序习惯：自定义顶栏、Tab、≥44px 触控

第一波界面不做：支付、积分、图像选品、收银、近场会员。

## 3. 页面清单（与产品一一对应）

### 3.1 顾客端 Tab：首页 · 分类 · 商品篮 · 我的

门店把会员码设为「底栏」时，顾客底栏在分类和商品篮之间多一项「会员码」。它不是常驻页：点进去打开会员码页（二维码 + 冒个泡），返回回到刚才的 Tab。设为「我的」时底栏仍是四项，会员码留在「我的」快捷卡。

| 页面 | 产品能力 | 原型交互要点 |
|------|----------|----------------|
| 首页 | 店名、履约摘要、进分类 | 头图最多 3 张，多于 1 张每 2.5 秒轮播；有公告时头图下跑马灯；配送/自提状态条（已设起送金额时配送副文案为满 x 元起送）；类目 chip；商品区按店配置 1/2/3 列加购；英雄区文案可读店配置 |
| 分类 | 本店类目 + 商品列表 | 左类目切换；行内 +/-；底栏去结算 |
| 商品详情 | 有货加购 / 售罄提醒 | 默认半屏抽屉（店可改整页）；完整页保留；**多图轮播**（≤3，仅 1 张无指示点） |
| 商品篮 | 改数量、结算 | 空态；角标；左右留边紧凑行（封面+名价+移除，右侧步进器，非通栏）；底栏去结算与分类页同款 |
| 结算 | 配送/自提、地址/时段、对应该方式的备注短语 | 三步指示；切换履约方式换一套短语；有余额时默认可抵，可关掉，账单显示还需当面付的金额；提交 loading→成功层 |
| 地址簿/编辑 | 手机小区楼栋室号 | 选择后返回结算 |
| 我的订单 | 列表筛选（可选 UX） | 进详情 |
| 订单详情 | 状态机、取消、客服、再来一单、我到店了 | **横向状态步**；行动区主次分明；取消前二次确认 |
| 我的 | 地址/订单/联系门店/积分/券/会员码/商家入口 | 身份卡为圆形头像加时段问候和昵称（上午好 / 下午好 / 晚上好），点头像打开半屏改资料；右侧上下为积分、余额可点块及数值，点进原页面；下方两张积分、余额快捷卡先隐藏；其下两列快捷卡；会员码页出示二维码，旁边可「冒个泡」；会员码改放底栏后这张卡不显示；联系门店半屏：电话拨打 + 在线客服；成员才显示工作台 |

### 3.2 商家端 Tab：订单 · 商品 · 设置 · 我的

| 页面 | 产品能力 | 原型交互要点 |
|------|----------|----------------|
| 订单台 | 待处理优先、到店标记 | 顶栏下状态导航切换「马上处理 / 备货中 / 配送中 / 待自提」，一次只看当前列表；到店脉冲；顶栏左上「用户端」回顾客首页（商品/设置同，我的页仍用原入口）；取消前二次确认 |
| 订单详情 | 推进/取消 | 横向状态 + 推进按钮；取消前二次确认 |
| 商品列表 | 上架/有货/首页推荐；名搜索与分类/推荐筛选；批量与删除 | **两列卡片**：有封面则铺满作背景，名价叠在图上；无图白底；底下一行三个状态（上架/下架、有货/售罄、推荐），点一下切换；点图文进编辑。工具栏「批量」进入多选，可全选当前筛选结果，底栏统一上架/下架/有货/售罄/推荐/取消推荐/删除 |
| **分类管理** | 本店分类 CRUD | 列表增删启用（单位不管这里） |
| 编辑商品 | 名/价/图/单位枚举/分类下拉/首页推荐；删除 | 单位写死枚举；分类动态；**图片最多 3 张**（小方图网格，可删）；首页推荐开关；已有商品可删除（二次确认） |
| 门店设置 | 顶栏导航：门店、首页、积分、实景、自提 | 一次只显示一组。头图最多 3 张（增删后即保存）、公告随保存设置提交（留空不展示）；文案；列数 1/2/3；点商品半屏/整页；积分比例、会员码入口（我的/底栏）、实景有效时间、配送起送金额与配送/自提两套备注短语走保存（起送不填不限制；两套收在同一块，导航切换；每套最多 8 句、每句 8 字，留空则该方式只手写）；自提时段添加删除立即生效。保存设置仍一次提交已填各项 |
| 商家我的 | 站内信、记积分、券、积分核销、邀人、回顾客端 | 两列快捷卡；站内信有未处理数时浅红底+角标；有人冒泡时「记积分」出红点；邀请通栏；回顾客端仍是独立色块 |

## 4. 数据绑定约定（防开发写死）

| UI 控件 | 数据来源 |
|---------|----------|
| 顾客左侧类目 / 首页 chip | `GET` 本店启用中的 `category` |
| 编辑商品 · 分类下拉 | 同上 |
| 编辑商品 · 单位下拉 | 客户端/服务端常量：`件` `份` `斤` |
| 自提时段 | 商家门店设置 |
| 首页履约摘要 | 店铺联系/时段配置的只读展示；已设 `min_delivery_fen` 时配送行显示满 x 元起送 |
| 点商品半屏或整页 | `store.product_detail_mode`（SHEET 默认 / PAGE） |
| 订单状态文案 | 统一映射表（见产品 §2.4 / 下表） |

## 5. 状态文案

| 状态码 | 配送 | 自提 |
|--------|------|------|
| PENDING_CONFIRM | 待确认 | 待确认 |
| PREPARING | 备货中 | 备货中 |
| DELIVERING | 配送中 | — |
| READY_PICKUP | — | 待自提 |
| COMPLETED | 已完成 | 已完成 |
| CANCELLED | 已取消 | 已取消 |

主按钮：**提交预约** / **加入商品篮** / **到货提醒我**。禁止「去支付」。

### 上架 / 有货

| 开关 | 开 | 关 |
|------|----|----|
| 上架 | 顾客可见 | 不可见 |
| 有货 | 可加购 | 售罄（可见不可买） |

售罄补货 = 打开「有货」（无库存数）。

---

## 6. 关键用户流

1. 预约配送：首页/分类加购 → 篮 → 结算配送+地址 → 提交成功 → 订单  
2. 预约自提：结算切自提 → 选时段 → 提交  
3. 售罄提醒：详情订阅 → 商家改有货 → 通知  
4. 再来一单 / 我到店了：见订单详情  
5. 商家：马上处理 → 推进；商品 → 分类管理 → 编辑商品  
6. 切端：我的 ↔ 商家工作台
