# Override: 顾客首页

继承 `MASTER.md`，本页额外规则：

- **导航左上角**固定店名（`store.name`）；头图大字用可配 **主标题**（`home_title`），留空则不显示，避免与导航重复
- 营业状态 pill、副标题可读店配置；空则回落客户端默认文案
- 其下用 **履约状态条**（配送/自提）建立信任，不做营销统计条
- 横向类目 chip → 进分类并带 filter
- 推荐商品列数由店配置：`1` 通栏行 / `2` 双列卡 / `3` 三列卡（等高，非瀑布流）
- 加购用较小圆形控件；三列用 `sm`；数量为 0 时仅 `+`
- 点图/品名：默认半屏商品详情（加购/到货提醒与详情页一致）；店配置为整页时跳转详情页；点加购控件不打开详情
- 推荐位可空；有货 SKU 优先展示；分类页仍用通栏列表
